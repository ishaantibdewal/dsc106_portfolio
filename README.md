# Portfolio site

**Live site: [ishaantibdewal.github.io/dsc106_portfolio](https://ishaantibdewal.github.io/dsc106_portfolio/)**

A personal portfolio site built for DSC 106 (Data Visualization) at UC San Diego, in plain HTML, CSS and
JavaScript with no framework.

- **Projects:** cards rendered from [`lib/projects.json`](lib/projects.json).
- **Meta:** a D3 scatter plot of this repo's own commits by date and time of day, with brushing to select
  commits and see lines of code by file type ([`meta/`](meta/)).
- Light/dark theme switch that remembers your choice, and a shared navigation bar injected by
  [`global.js`](global.js).
